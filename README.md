# Virtual Labs – Immersive MR & VR Learning Experience

An immersive MR/VR learning experience featuring interactive Circuit & IoT, Chemistry, and Physics labs.

## Overview

Virtual Labs is a Unity-based immersive learning experience designed to provide interactive virtual experiments in different scientific fields.

## Features

- Interactive Circuit & IoT laboratory
- Chemistry experiments
- Physics experiments
- Interactive virtual learning environments
- MR/VR learning experiences
- ESP32 and IoT integration for physical hardware interaction

## Technologies

- Unity
- C#
- ESP32
- IoT
- MR/VR

## Project Structure

- `Assets/` — Project assets, scenes, scripts, materials, and other Unity content
- `Packages/` — Unity package configuration
- `ProjectSettings/` — Unity project settings

## Project Status

This project is developed as an immersive educational experience combining virtual environments with interactive experiments and IoT hardware.
